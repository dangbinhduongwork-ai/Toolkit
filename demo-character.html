🚶 Demo Nhân Vật Đi Dưới Đáy Màn Hình

Trang web mẫu này minh họa nhân vật 3D đi lại tự do dưới chân website của bạn. Bạn có thể dùng chuột hoặc ngón tay kéo nhân vật lên cao rồi thả ra để xem trọng lực rơi tự do!

📂 Thử trực tiếp với file GLB của bạn

📁 Nhấp vào đây để chọn file .glb trên máy của bạn

📋 Cách nhúng vào Website của bạn (Chỉ 3 dòng)

<!-- 1. Thêm importmap trong thẻ <head> -->
<script type="importmap">
{
  "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.186.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.186.0/examples/jsm/"
  }
}
</script>

<!-- 2. Gọi module WalkingCharacter -->
<script type="module">
  import { WalkingCharacter } from './modules/walking-character.js';

  new WalkingCharacter({
    modelUrl: './models/your-character.glb', // Đường dẫn file .glb của bạn
    scale: 120,    // Chiều cao nhân vật (px)
    speed: 90,     // Tốc độ đi bộ
    floorOffset: 15 // Cách mép đáy màn hình (px)
  });
</script>
