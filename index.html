🚶 Nhân vật 3D đi lại dưới đáy màn hình (Mascot)

Nhân vật tự động đi qua đi lại ở chân website. Bạn có thể dùng chuột hoặc ngón tay kéo chú lên cao rồi thả ra để xem chú rơi tự do và nảy nhẹ chạm đất!

🎮 Mở Trang Demo & Chỉnh Sliders Tốc Độ/Kích Thước
> node installer.mjs character <đường_dẫn_dự_án>

Code nhúng vào React / Next.js:

import { WalkingCharacter } from './components/ui/WalkingCharacter';

export default function App() {
  return (
    <div>
      {/* Nhân vật 3D đi lại chân màn hình */}
      <WalkingCharacter 
        modelUrl="/models/chibi_bald_business_man_walk.glb"
        scale={125}  // Chiều cao pixel
        speed={85}   // Tốc độ di chuyển
      />
    </div>
  );
}

🌊 Mô phỏng Sóng nước Vật lý (2.5D Wave Grid)

Sử dụng toán tử vi phân Laplace 9 điểm giúp sóng nước tròn đều, chân thực và có dải tiêu biến biên không bị dội sóng. Hãy bấm hoặc rê chuột vào khung dưới đây:

👆 Chạm hoặc khuấy chuột vào đây để tạo sóng
> node installer.mjs ripple <đường_dẫn_dự_án>

Code nhúng vào React (chỉ 2 dòng):

import { useRef } from 'react';
import { useWaterRipple } from './hooks/useWaterRipple';

export function WaterBackground() {
  const canvasRef = useRef(null);
  useWaterRipple(canvasRef); // Tự động gắn bộ mô phỏng sóng nước

  return <canvas ref={canvasRef} className="fixed inset-0 pointer-events-none z-10" />;
}

🎧 Web Audio API - Vi tương tác âm thanh & ASMR

Âm thanh phát tức thì không độ trễ. Tự động ngẫu nhiên hóa cao độ nhẹ (pitch variance) mỗi lần bấm để tiếng không bị cơ học nhàm chán. Giải quyết 100% lỗi chặn Autoplay trên iOS Safari.

> node installer.mjs audio <đường_dẫn_dự_án>

Code nhúng vào React:

import { useAudio } from './hooks/useAudio';

export function MyButton() {
  const { play } = useAudio({ pop: '/audio/pop.mp3' });

  return (
    <button onClick={() => play('pop', { pitchVariance: 0.1 })}>
      Bấm nút nghe tiếng ASMR
    </button>
  );
}

⚡ Script tự động cài đặt 1 lệnh (`installer.mjs`)

Bạn không cần copy file thủ công! Chỉ cần mở Terminal và gõ 1 dòng lệnh, công cụ sẽ tự động copy đúng component React hoặc script HTML vào dự án của bạn:

Cài đặt nhân vật 3D vào dự án:

node E:\25.Mykey\tools\installer.mjs character <đường_dẫn_project>

Cài đặt sóng nước tương tác:

node E:\25.Mykey\tools\installer.mjs ripple <đường_dẫn_project>

Cài đặt 12 kỹ năng AI Coding (Skills cho Cursor/Claude):

node E:\25.Mykey\tools\installer.mjs skills <đường_dẫn_project>

Cài đặt tất cả tính năng cùng lúc:

node E:\25.Mykey\tools\installer.mjs all <đường_dẫn_project>
